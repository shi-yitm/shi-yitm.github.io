GitHub Pages 搭建指南

📅 2026-06-04 📂 博客

最简单、最免费的建站方式，只需要一个 GitHub 账号就能搞定。

GitHub Pages 是 GitHub 提供的一项免费静态托管服务。你只要把 HTML/CSS/JS 文件推送到仓库里，GitHub 会自动帮你部署，生成一个可访问的网址。整个过程不需要买服务器、不需要配置 Nginx、不需要备案。

两种 Pages 类型

GitHub Pages 分两种：

  • 用户/组织站点 — 一个账号只能有一个，仓库名必须是 用户名.github.io。这是你的个人官网。
  • 项目站点 — 每个仓库都可以开启，访问地址是 用户名.github.io/仓库名。适合给每个项目单独建站。

我个人建站用的是用户站点，也就是你现在正在看的这个网站。

建站步骤

第一步：创建仓库

登录 GitHub，点右上角的 + → New repository。

仓库名填 你的用户名.github.io。比如你的用户名是 shi-yitm，那仓库名就是 shi-yitm.github.io。这个名字必须完全匹配，否则不会生效。

设为 Public（公开仓库），然后点 Create repository。

第二步：上传文件

你有两种方式把文件放上去：

  • 网页上传 — 打开仓库页面，点 Add file → Upload files，把本地的 index.html 等文件拖进去，Commit 即可。
  • Git 命令行 — 先 git clone 仓库到本地，然后把文件放进去，git add、git commit、git push。

第三步：访问你的网站

上传完成后等 1-2 分钟，打开浏览器访问：

https://你的用户名.github.io

如果看到了你的页面，恭喜你！你的第一个网站上线了 🎉

目录结构规范

文件都放在仓库根目录，GitHub Pages 会自动识别 index.html 作为首页：

你的用户名.github.io/
├── index.html       ← 首页（必须）
├── blog.html        ← 其他页面
├── post.html        ← 文章页
├── about.html
├── style.css
└── script.js

绑定自定义域名

如果你想用 shiyi.me 这样的域名而不是 用户名.github.io，可以买一个域名然后绑定：

  1. 在域名服务商那里（比如阿里云）买个域名，大概几十块一年
  2. 在 DNS 设置里添加一条 CNAME 记录，指向 你的用户名.github.io
  3. 在仓库的 Settings → Pages → Custom domain 里填上你的域名

绑定成功后，访问你的域名就能看到网站了。

日常更新流程

以后每次想更新内容，三步走：

git add .
git commit -m "写清楚改了什么"
git push

推送后等一两分钟，网站自动更新，不需要手动部署任何东西。

优缺点总结

优点 缺点
完全免费，没有隐藏费用 只支持静态文件（HTML/JS/CSS）
自动 HTTPS，不用配证书 不能跑后端代码（Java/PHP/Python）
和 Git 无缝集成，部署超简单 国内访问速度有时不太稳定
不需要管服务器运维 存储空间限制 1GB

总的来说，对于个人博客、产品展示页、项目文档来说，GitHub Pages 是最简单、最经济的方案。等以后网站做大了、需要数据库了，再迁移到服务器也不迟。
