GitHub Pages 搭建指南

📅 2026-06-07👁 0 次阅读 #GitHub #教程 #部署

什么是 GitHub Pages

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。你只需要把 HTML 文件推送到仓库，它就会自动生成一个网站。

创建仓库

  1. 在 GitHub 上创建一个名为 你的用户名.github.io 的仓库
  2. 把仓库 clone 到本地
  3. 在仓库根目录放一个 index.html

部署

git add .
git commit -m "初始化网站"
git push origin main

推送完成后，等待几秒钟，访问 https://你的用户名.github.io 就能看到你的网站了！

自定义域名

如果不想用 github.io 结尾的域名，可以买一个自己的域名，在 GitHub Pages 的 Settings 里配置 Custom domain 即可。

小结

GitHub Pages 是入门个人网站搭建的最佳选择——免费、简单、稳定。唯一的限制是只能托管静态内容，如果需要后端功能，就得考虑云服务器了。
