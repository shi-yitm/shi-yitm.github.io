我的第一个个人网站

📅 2026-06-04 👁 0 次阅读 #博客 #GitHub Pages

终于，我有了自己的个人网站。

说来也挺有意思的——一直在学习 Web 开发，给别人做项目，却从来没给自己搭一个站点。这次决定从零开始，用自己的技术栈做一个真正属于自己的地方。

为什么选择 GitHub Pages？

免费的、稳定的、和 Git 无缝集成的托管方案。对于个人博客来说，简直是最佳起点。不需要买服务器、不需要配 Nginx、不需要管备案——把 HTML 文件往仓库里一推，世界就能看到了。

这个网站打算放什么

  • 技术笔记 — 学习过程中的踩坑与收获
  • 项目总结 — 做过的项目回顾
  • 随笔 — 偶尔写点生活感悟

下一步计划

目前是纯静态页面。以后逐步添加：分类标签、搜索、评论功能……一点点让它丰富起来。

过程比结果重要。慢慢来，比较快。

种一棵树最好的时间是十年前，其次是现在。
