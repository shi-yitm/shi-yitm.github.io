📅 2026-07-07 #JavaWeb #过滤器 #DAO #考试复习

📝 第一题：过滤器实现注册校验

题目场景：员工管理系统中，注册页面 register.jsp 有姓名（uname）、密码（pwd）两个文本框，通过过滤器对请求数据进行校验，校验失败跳转回注册页面并显示错误提示。

校验规则：

  • 姓名：长度为6个字符，且必须是小写字母和数字的组合
  • 密码：必须是6位数字

一、register.jsp 页面

<%@ page language="java" contentType="text/html; charset=utf-8"
    pageEncoding="utf-8"%>
<html>
<head>
<title>Insert title here</title>
</head>
<body>
  <span style="color: red">_____1_____</span>
  <form action="_____2_____" method="post">
    用户名：<input type="_____3_____" name="uname" /><br/>
    密&nbsp;&nbsp;&nbsp;码：<input type="text" name="pwd" /><br/>
    <input type="submit" value="提交" />
    <input type="reset" value="重置" />
  </form>
</body>
</html>

空1：${msg}

过滤器校验失败时用 req.setAttribute("msg", "错误信息") 把错误信息存到了 request 域中。EL 表达式 ${msg} 会自动从域中查找名为 msg 的属性并输出其值。如果校验通过（没有设置 msg），则 EL 表达式输出空字符串，页面不显示任何红色文字。

空2：DoRegister

表单的 action 属性指定表单提交到哪个 Servlet 处理。看 web.xml 中 servlet-mapping 的配置，URL 是 /doRegister。表单提交后，请求会先经过过滤器（URL 匹配 /DoRegister），校验通过后放行到 Servlet。

空3：text

用户名是一个普通的文本输入框，题目中也明确说了"姓名（uname）文本框"，文本框的 type 就是 text。

二、过滤器 RegisterFilter

public class RegisterFilter implements Filter {
    public RegisterFilter() {}
    public void destroy() {}

    public void _____4_____ (ServletRequest request, ServletResponse response,
            FilterChain chain) throws IOException, ServletException {

        HttpServletRequest req = (HttpServletRequest)request;
        req. _____5_____ ("utf-8");

        String uname = req.getParameter("uname");
        String pwd = req.getParameter("pwd");

        String str1 = "^[0-9a-zA-Z]{6}$";
        String str = "^[0-9]{6}$";

        if(Pattern.matches(str1, uname) && Pattern.matches(str, pwd)) {
            chain. _____6_____ (request, response);
        }
        else if(!Pattern.matches(str1, uname)) {
            req. _____7_____ ("msg", "长度为6个字符，且必须是小写字母和数字的组合");
            req.getRequestDispatcher("register.jsp")._____8_____ (request, response);
        }
        else if(!Pattern.matches(str, pwd)) {
            req.setAttribute("msg", "密码必须是6位数字");
            req.getRequestDispatcher("register.jsp").forward(request, response);
        }
    }

    public void init(FilterConfig fConfig) throws ServletException {}
}

空4：doFilter

这是 javax.servlet.Filter 接口的核心方法。过滤器必须实现 doFilter() 方法，每次请求匹配的 URL 时都会调用。方法签名是固定的：

public void doFilter(ServletRequest request, ServletResponse response,
    FilterChain chain) throws IOException, ServletException

三个参数的含义：request 封装请求数据，response 封装响应数据，chain 过滤器链，用于决定是否放行请求。

空5：setCharacterEncoding

HttpServletRequest 继承自 ServletRequest，setCharacterEncoding(String charset) 方法用于设置请求体的字符编码。这是解决 POST 请求中文乱码的标准做法，必须在获取任何请求参数之前调用。

空6：doFilter

FilterChain 接口的 doFilter() 方法用于放行请求，让请求继续传递到下一个过滤器或目标 Servlet。如果不调用 chain.doFilter()，请求就被"拦截"了，不会到达后面的 Servlet。

空7：setAttribute

HttpServletRequest 的 setAttribute(String name, Object value) 方法用于将数据存入 request 作用域。这样在转发到的 register.jsp 页面中，就可以用 EL 表达式 ${msg} 取出这个值显示错误提示。作用域范围：只在当前请求内有效。

空8：forward

RequestDispatcher 接口的 forward(ServletRequest, ServletResponse) 方法用于请求转发。转发是服务器内部行为，浏览器地址栏不变。转发后用户看到的还是表单页面，但多了错误提示。

三、控制器 DoRegister

public class DoRegister extends HttpServlet {
    public DoRegister() { super(); }

    protected void doGet(_____9_____ request, HttpServletResponse response)
            throws ServletException, IOException {
        request.setCharacterEncoding("utf-8");
        String uname = request. _____10_____ ("uname");
        String pwd = request.getParameter("pwd");
        PrintWriter out = response.getWriter();
        out.print(uname + ":" + pwd);
    }

    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        doGet(request, response);
    }
}

空9：HttpServletRequest

doGet() 方法的第一个参数是请求对象。因为这是处理 HTTP 请求的 Servlet，所以类型是 HttpServletRequest（而不是 ServletRequest）。继承关系：ServletRequest（接口）→ HttpServletRequest（接口，HTTP 专用）→ HttpServlet（抽象类）。

空10：getParameter

HttpServletRequest 的 getParameter(String name) 方法用于获取表单中 name 属性对应的值。request.getParameter("uname") 就能拿到用户在 uname 文本框中输入的内容。这里 name 参数必须和表单中的 name 属性完全一致。

四、web.xml 配置

<filter>
    <filter-name>registerFilter</filter-name>
    <filter-class>_____11_____</filter-class>
</filter>
<filter-mapping>
    <filter-name>_____12_____</filter-name>
    <url-pattern>_____13_____</url-pattern>
</filter-mapping>

<servlet>
    <servlet-name>doRegister</servlet-name>
    <servlet-class>_____14_____</servlet-class>
</servlet>
<servlet-mapping>
    <servlet-name>_____15_____</servlet-name>
    <url-pattern>/doRegister</url-pattern>
</servlet-mapping>

空11：com.hkd.filter.RegisterFilter

filter-class 必须填过滤器类的完整包名+类名。题目已知包名为 com.hkd.filter，类名为 RegisterFilter，拼起来就是 com.hkd.filter.RegisterFilter。Servlet 容器（Tomcat）根据这个全限定类名通过反射创建过滤器实例。

空12：registerFilter

<filter-name> 是过滤器的逻辑名称，用于在 <filter> 和 <filter-mapping> 之间建立关联。名称可以自定义，但两处必须完全一致。

空13：/DoRegister

<url-pattern> 指定过滤器拦截哪些 URL 的请求。过滤器要拦截提交到 DoRegister 的表单请求，所以 URL 必须和 Servlet 的 url-pattern 一致。

空14：com.hkd.servlet.DoRegister

和过滤器同理，<servlet-class> 必须填 Servlet 类的完整包名+类名。包名 com.hkd.servlet，类名 DoRegister。

空15：doRegister

<servlet-name> 是 Servlet 的逻辑名称，在 <servlet> 和 <servlet-mapping> 之间建立关联，两处必须一致。

🔗 整体执行流程

用户提交表单 (POST /DoRegister)
       ↓
  RegisterFilter.doFilter()
       ↓
  setCharacterEncoding("utf-8")  ← 解决中文乱码
       ↓
  获取 uname 和 pwd 参数
       ↓
  正则校验 ──── 通过 → chain.doFilter() → DoRegister Servlet → 显示用户名:密码
       ↓ 不通过
  setAttribute("msg", "错误信息")
       ↓
  forward → register.jsp → ${msg} 显示红色错误提示

📝 第二题：DAO模式实现管理员信息修改

题目场景：员工管理系统中，数据库为 company，管理员表 manager 包含字段：mid（编号）、mname（名称）、mpwd（密码）、mphone（电话）。构建 DAO 模式四部分，实现修改管理员信息的功能。

一、工具类 DataBase

空1：com.mysql.cj.jdbc.Driver

这是 MySQL 8.x 的 JDBC 驱动类完整类名。JDBC 通过这个类名加载驱动。MySQL 版本不同类名不同：MySQL 8.x 用 com.mysql.cj.jdbc.Driver（新版本，带 .cj），MySQL 5.x 用 com.mysql.jdbc.Driver（旧版本）。现在基本都用 8.x。

空2：company

题目明确说了"数据库为 company"。JDBC URL 格式：jdbc:mysql://主机:端口/数据库名。jdbc:mysql:// 是协议，localhost:3306 是本机 MySQL 默认端口，company 是要连接的数据库名。

空3：forName

Class.forName(String className) 是 Java 反射方法，通过类名字符串加载类。这是 JDBC 加载驱动的标准写法：Class.forName("com.mysql.cj.jdbc.Driver") → 加载驱动类 → 触发类的 static 块 → 在 DriverManager 中注册驱动。

空4：DriverManager

DriverManager 是 JDBC 的驱动管理器，它的 getConnection() 方法用于获取数据库连接。这是 JDBC 三步走的核心第二步：Class.forName() 加载驱动 → DriverManager.getConnection() 获取连接 → conn.createStatement() 创建语句对象。

空5：createStatement

Connection 接口的 createStatement() 方法用于创建 Statement 对象。Statement 对象的作用是向数据库发送 SQL 语句。执行流程：Connection → createStatement() → Statement → executeUpdate(sql)。

空6：executeUpdate

Statement 接口的 executeUpdate(String sql) 方法用于执行增（INSERT）、删（DELETE）、改（UPDATE）操作，返回值是受影响的行数（int 类型）。方法名 executeZSG 中的 ZSG 就是"增删改"的拼音缩写。

二、实体类 Manager

    public String getMphone() {
        return mphone;
    }
    public void setMphone(String mphone) {
        this.mphone = _________7_______;

空7：mphone

setter 方法的职责是将参数值赋给对应的私有属性。setMphone(String mphone) 对应 mphone 字段，所以用 this.mphone = mphone。JavaBean 规范：字段名 mphone，setter setMphone(String mphone) → this.mphone = mphone。

三、Dao 接口

public _________8_______ ManagerDao {
    public int updateManager(_________9_______ manager);
}

空8：interface

interface 是 Java 定义接口的关键字。Dao 接口定义了数据访问层的规范（方法签名），不包含具体实现。接口的特点：所有方法默认 public abstract，只定义方法签名不写方法体，实现类必须重写所有方法。

空9：Manager

修改管理员信息，需要传入一个包含新数据的 Manager 对象。参数类型就是实体类 Manager，这样实现类可以通过 manager.getMname() 等方法获取要修改的值。

四、Dao 实现类

public class ManagerDaoImp extends _________10_______ implements _________11_______ {

            + manager.getMphone() + "' where mid='"
            + _________13_______() + "'";

        int result = 0;
        result = this._________14_______(sql);
        return _________15_______;
    }
}

空10：DataBase

extends DataBase 表示继承工具类。这样实现类就拥有了 DataBase 中的 conn（数据库连接对象）、sm（Statement 对象）、rs（ResultSet 对象）、executeZSG()（执行增删改的方法）、closeDb()（关闭连接的方法）。这就是 DAO 模式中"工具类"的价值——实现类不用重复写连接数据库的代码。

空11：ManagerDao

implements ManagerDao 表示实现 Dao 接口。实现类必须重写接口中定义的所有方法，也就是 updateManager()。整体设计：ManagerDao（接口）定义规范 → ManagerDaoImp（实现类）具体实现 → DataBase（工具类）提供基础设施 → Manager（实体类）封装数据。

空12：update

SQL 修改语句的语法是 UPDATE 表名 SET 字段1=值1, 字段2=值2 WHERE 条件。update 关键字用于修改表中的数据。完整 SQL 拼接后类似：

update manager set mname='张三', mpwd='123456', mphone='13800138000' where mid='001'

空13：manager.getMid()

SQL 的 WHERE 条件要根据管理员编号（mid）定位要修改的记录。manager 对象中保存了要修改的管理员信息，通过 getMid() 获取其编号。如果不加 WHERE 条件，UPDATE 会修改所有行，这是非常危险的！

空14：executeZSG

this.executeZSG(sql) 调用的是从父类 DataBase 继承来的增删改方法。this 代表当前对象，因为 ManagerDaoImp 继承了 DataBase，所以可以直接调用。executeZSG 内部：获取连接 → 创建 Statement → 执行 SQL → 返回受影响行数。

空15：result

方法的返回值类型是 int，表示修改操作影响的行数。result 变量存储了 executeZSG() 的返回值，直接 return 即可。返回 1 表示修改成功（1行受影响），返回 0 表示修改失败（没有匹配的记录）。

⚠️ 注意事项

  1. SQL 注入风险：题目用字符串拼接 SQL，实际开发中应该用 PreparedStatement 的参数化查询
  2. 资源泄漏：executeZSG() 中没有在 finally 中关闭资源，实际开发应该加上
  3. 空14 的方法名：工具类方法名是 executeZSG（增删改），虽然语义上叫"执行增删改"，但它内部调用的是 executeUpdate()，所以 UPDATE 也能正常执行
