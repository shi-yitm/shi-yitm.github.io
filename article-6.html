用 DeepSeek 免费跑 Codex CLI：CC-Switch 协议转换部署指南

📅 2026-06-07👁 1 次阅读 #DeepSeek #Codex #AI #教程

前言

OpenAI 的 Codex CLI 是一个强大的 AI 编程助手，但需要 OpenAI API Key，价格不菲。而 DeepSeek 提供了免费额度的 API。通过 CC-Switch 协议转换工具，可以让 Codex CLI 走 DeepSeek 的 API。

什么是 CC-Switch

CC-Switch 是一个 API 协议转换工具，它能将 OpenAI 格式的 API 请求转换成其他 LLM 提供商的格式。

部署步骤

1. 安装 CC-Switch

git clone https://github.com/deepseek-community/ccswitch.git
cd ccswitch
npm install

2. 配置 DeepSeek API

在配置文件中填入你的 DeepSeek API Key 和端点地址。

3. 启动服务

npm start

CC-Switch 会在本地启动一个服务，Codex CLI 连接到这个本地服务，CC-Switch 再将请求转发到 DeepSeek API。

使用 Codex CLI

配置 Codex CLI 使用本地代理端点后，就可以正常使用了。体验和用 OpenAI 官方 API 几乎一样！

注意事项

  • DeepSeek 免费额度有限，合理使用
  • 复杂任务的响应质量可能会有差异
  • 建议配合本地模型一起使用

总结

通过 CC-Switch，可以零成本体验 Codex CLI 的核心功能。对于学生和个人开发者来说，这是一个很好的方案。
