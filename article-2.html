我的第一个个人网站

📅 2026-06-07👁 0 次阅读 #网站 #入门

前言

一直想有一个属于自己的网站，记录学习和生活中的点点滴滴。经过一番摸索，终于把第一个个人网站搭建起来了。

技术选型

刚开始做网站的时候，选择了最基础的技术栈：HTML + CSS + JavaScript，部署在 GitHub Pages。选这套方案的原因很简单——免费、稳定、学习曲线平缓。

搭建过程

从 HTML 标签学起，一步步搭建页面结构、设计样式、添加交互。虽然很基础，但每一步都是自己亲手写出来的，感觉特别充实。

收获

第一个网站虽然简陋，但让我对前端开发有了完整的认识。从页面结构到样式布局再到部署上线，整个流程都走了一遍。

写在最后

这个网站会一直迭代下去，记录我的成长。

感谢阅读，欢迎留言交流！
