核心代码

fetch_balance.py · usage 汇总
def compute_usage_stats(usage_data):
    today = datetime.date.today().isoformat()
    total_tokens = 0
    model_breakdown = {}

    for model in usage_data.get("total", []):
        model_total = sum(int(u["amount"]) for u in model["usage"])
        total_tokens += model_total
        model_breakdown[model["model"]] = model_total

    return {
        "total_tokens": total_tokens,
        "model_breakdown": model_breakdown,
    }

02 已完成

个人博客 CMS 管理系统

博客系统从本地 CMS 迁移到服务器端部署。前台 Nginx 静态托管，后台 Node.js + sql.js 运行在服务器上，支持文章管理、项目管理、拖拽排序、密码保护。

▾
Node.js Express SQLite Nginx

架构概览

前后端分离架构：CMS 后台跑在本地 Windows（localhost:3000），服务器上 Nginx 托管静态前端，后台不在公网暴露保证安全性。

Editor
admin.html
Markdown 编辑器 + 实时预览
API
Express + SQLite
文章 CRUD、自动保存
Deploy
deploy.js
生成静态 HTML → SCP 上传
Serve
Nginx
腾讯云服务器 80 端口托管

技术选型

数据库用 SQLite 而非 MySQL，因为个人博客不需要复杂关系查询，单文件部署最省心。服务器端用 sql.js（WASM）替代 better-sqlite3，绕过了 GLIBC 兼容性问题。
