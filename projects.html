02 · Desktop Widget

DeepSeek API 用量实时监控小组件

用 Python、pywebview 和前端页面做的 Windows 桌面小组件，用来查看 DeepSeek API 余额、Token 消耗、模型分布和 7 日趋势。

已完成
Python pywebview HTML/CSS/JS DeepSeek API
阅读项目复盘 →

架构图

这个项目的核心是一条本地数据链路：后台采集器负责拿数据，桌面组件只负责读取和展示。这样 UI 不直接碰 API，也更容易定位问题。

Source
DeepSeek API
读取账户余额和平台用量数据。
Fetcher
fetch_balance.py
定时请求接口，计算总量、今日用量、模型分布和 7 日趋势。
Cache
balance.json
作为本地数据缓存，避免 UI 直接依赖网络请求。
Widget
widget.html / pywebview
通过 JS bridge 读取 JSON，渲染余额、进度条和图表。

核心代码摘录

下面保留的是项目最能说明结构的代码：采集器如何汇总 usage，以及前端如何通过 bridge 读取本地数据。密钥和敏感配置没有展示。

fetch_balance.pyusage 汇总
def compute_usage_stats(usage_data):
    today = datetime.date.today().isoformat()
    total_tokens = 0
    model_breakdown = {}
    usage_types = {}

    for model in usage_data.get("total", []):
        model_total = sum(int(u["amount"]) for u in model["usage"])
        total_tokens += model_total
        model_breakdown[model["model"]] = model_total
        usage_types[model["model"]] = {
            u["type"]: int(u["amount"]) for u in model["usage"]
        }

    seven_days = []
    for day in usage_data.get("days", []):
        if day["date"] <= today:
            total = sum(
                sum(int(u["amount"]) for u in m["usage"])
                for m in day["data"]
            )
            seven_days.append({"date": day["date"], "tokens": total})

    return {
        "total_tokens": total_tokens,
        "model_breakdown": model_breakdown,
        "usage_types": usage_types,
        "seven_days": sorted(seven_days, key=lambda x: x["date"]),
    }
widget.htmlJS bridge 读取数据
async function refresh() {
  let raw;
  if (window.pywebview && window.pywebview.api) {
    raw = await window.pywebview.api.get_data();
  } else {
    const resp = await fetch('/balance.json?' + Date.now());
    raw = await resp.text();
  }

  const data = JSON.parse(raw);
  document.getElementById('balance').textContent =
    '¥' + fmtCNY(data.balance);
  document.getElementById('bigNumber').textContent =
    fmt(data.used_tokens || 0);

  const pct = Math.min((data.used_tokens || 0) / budget * 100, 100);
  document.getElementById('progressFill').style.width = pct + '%';
}
