从零到上线：腾讯云轻量服务器部署个人博客全记录

📅 2026-06-07👁 0 次阅读 #部署 #腾讯云 #博客 #Nginx #Node.js

缘起

一直想把之前用 GitHub Pages 托管的个人博客搬到自己的云服务器上，刚好看到腾讯云有轻量应用服务器试用活动，2核2G3M的配置跑个人博客绰绰有余。于是凌晨蹲点抢到了一台。

第一步：申请服务器

腾讯云轻量应用服务器试用活动每天限量，第一天没抢到，第二天凌晨十二点准时抢到了。初始选了 Windows 系统，但考虑到 Node.js 在 Linux 上更高效，果断重装成 Ubuntu 22.04 LTS。

第二步：SSH 连接与密钥配置

重装后遇到几个坑：防火墙没开 22 端口、默认用户是 ubuntu 而非 root、SSH 密钥权限问题。最终采用 SSH 密钥对方式登录，在本地生成 RSA 4096 位密钥，公钥写入服务器 authorized_keys。

第三步：安装运行环境

连上服务器后，装了 Node.js v20、Nginx 1.18、PM2 进程守护。一切顺利。

第四步：部署博客前端

把博客静态文件从 GitHub 拉到服务器，放到 Nginx 托管目录。踩了权限坑——Nginx 以 www-data 运行，读不了 /root 下的文件，移到了 /var/www/blog/ 解决。

第五步：本地 CMS + 自动部署

后台 CMS 只在本机运行（localhost:3000），写完文章自动触发生成静态 HTML + scp 上传服务器。deploy.js 只传 HTML，不动 CSS/JS。用 sql.js 替代 better-sqlite3 避免原生模块编译问题。

踩坑总结

  1. 腾讯云防火墙记得开 22 和 80 端口
  2. /root 目录权限 Nginx 读不到
  3. SQLite 原生模块兼容性用 sql.js 解决
  4. deploy 只碰 HTML 不动样式文件
  5. 试用到正式买服务器时先建镜像快照
