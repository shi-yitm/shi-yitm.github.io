学习笔记：JavaScript 基础

📁 技术 📅 2026/6/5 👁 1 次阅读
#JavaScript#学习笔记

JavaScript 基础知识

变量声明

const name = "十一";  // 常量
let age = 20;          // 可变变量

函数

// 箭头函数
const greet = (name) => {
  return 你好，${name}！;
};
console.log(greet("十一"));

数组方法

const nums = [1, 2, 3, 4, 5];
// map - 映射
const doubled = nums.map(n => n * 2);
// filter - 过滤
const evens = nums.filter(n => n % 2 === 0);
// reduce - 归纳
const sum = nums.reduce((acc, n) => acc + n, 0);

异步编程

const fetchData = async () => {
  const res = await fetch("/api/data");
  const data = await res.json();
  return data;
};

JavaScript 是一门灵活的语言，学好基础很重要！
