用 Node.js 从零搭建个人博客后台管理系统

📅 2026-06-07👁 0 次阅读 #Node.js #博客 #后端

为什么自己搭后台

GitHub Pages 托管静态博客很方便，但每次写文章都要手动创建 HTML 文件，太麻烦了。于是决定用 Node.js 搭一个后台管理系统。

技术栈

  • Express：轻量级 Node.js Web 框架
  • SQLite：零配置的嵌入式数据库
  • marked.js：Markdown 渲染
  • PM2：进程守护

核心功能

  1. 文章管理：新增、编辑、删除文章，支持 Markdown 写作
  2. 分类与标签：文章分类管理
  3. 阅读量统计
  4. 静态部署：一键生成静态 HTML 并部署

架构设计

后台本地运行（localhost:3000），写文章后自动生成静态 HTML 推送到服务器。后台不暴露在公网上，安全可靠。

总结

自己动手搭后台管理系统，让我对 Web 全栈开发有了更深的理解。
